# Workflow: pre-production (v0.1.0)

Kinds: `preproduction`.
`plan-job.js` keeps a row when its Condition holds. Conditions: `always`, `if:tag`, `unless:tag`.
Tags for this workflow: `has_trailer` (trailer milestones tracked separately), `multi_day` (more than one shoot day), `gate_A`, `gate_B`, `gate_C`.
Role is the agent's role name, or `-` for a script row or a board row (a gate the human decides on the Pre-production board). Owner is always `orchestrator` for this workflow; every director is `support`.
`XX` in the Task column means the row waits on a human and the board card is set to `needs_input`.

## Change propagation (R04)

A change request on the board for any approved item sets it and every dependent item to `needs_review`, reopens only the gate that item belongs to, and lands as an inbox row the orchestrator reads on `board-sync.js pull`. The orchestrator re-enters the row that owns the changed item; nothing downstream is regenerated until that row is re-approved. Previous versions are never deleted.

| Changed | Sent back for review |
|---|---|
| intake | scraper, script, storyboard, shot list, budget, timeline, audio, registers, breakdown, call sheets |
| script | storyboard, shot list, budget, timeline, audio, props, locations, breakdown, call sheets |
| storyboard | shot list, audio, props, locations, breakdown, call sheets |
| shot list | budget, timeline, talents, props, locations, breakdown, call sheets |
| any register or audio | breakdown, call sheets |
| timeline | call sheets |
